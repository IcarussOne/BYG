# Oh The Biomes You'll Go: Legacy Edition Wiki

This directory contains the documentation and wiki for the **Oh The Biomes You'll Go: Legacy Edition (BYG)**, a Minecraft 1.12.2 biome mod. 

The live wiki is available at: [https://windanesz.github.io/BYG](https://windanesz.github.io/BYG)

## Local Development

The wiki is built using [Docusaurus](https://docusaurus.io/). To run it locally:

```bash
# Install dependencies
yarn

# Start the local development server
yarn start
```

## Build

```bash
yarn build
```

This command generates static content into the `build` directory and can be served using any static contents hosting service.
