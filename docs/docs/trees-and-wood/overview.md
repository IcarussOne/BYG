# Trees and Wood: Overview

Most BYG trees come as a **wood set**: a family of blocks made from one kind of log. The [Wood Sets](wood-sets.md) page lists every family and which blocks it has. [Saplings and Growth](saplings-and-growth.md) explains how to grow the trees.

## Turning a set off

Every set has an on/off option under **Content Settings** in the BYG config. Turning one off removes its blocks, items, recipes and world generation together with its biome content. It needs a Minecraft restart, and it should only be changed before you create a world, or blocks already placed will go missing.
