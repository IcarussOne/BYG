# Oh The Biomes You'll Go: Legacy Edition

Wiki for **BYG**, a Minecraft Forge 1.12.2 biome mod.

This mod is a rewrite of the original 1.12.2 MCreator-based Oh The Biomes You'll Go mod of AOCAWOL, brought to you by WinDanesz.

The rewrite recreates all features of the original 1.12.2 version in Java code, published with the permission of AOCAWOL. No assets, code or other content was backported from post-1.12 versions of BYG (or Oh The Biomes We've Gone). Please, don't even ask for them, as this rewrite only has permission for the 1.12.2 content.

If you are interested in the original mod and its post-1.12 versions, you can find it on [CurseForge](https://www.curseforge.com/minecraft/mc-mods/oh-the-biomes-youll-go).
### Notable changes from BYG 1.12.2 (the latest original v1.7.1 BiomesYouGo)
- No more MCreator. The mod was rewritten to be more performant
- Improvements to worldgen (fixed cascading worldgen lag)
- Extensive configurations, some notable:
  - Individual biomes can be disabled, or have weights altered
  - Biome-related content (blocks, items, recipes, etc…) can be entirely disabled, skipping registering them. This also disables relevant biomes. E.g. disabling the Ebony Wood set also disables the Ebony Woods biome
  - Disable to deregister armour sets and their ores
- Tweak food levels, armour levels, etc.
- Crystal Crawler is a new mob for the Crystal Canyon biome
- Baobab Powder can be used to brew a Potion of Clarity
- Golden Beetroot can be fed to tamed mobs to grant them passive healing
- Kiwi mobs have a proper AI, and they can also be bred, and be helpful to obtain worms for fishing
