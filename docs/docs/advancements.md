# Advancements

BYG adds a small advancement tab called **Oh The Places You'll Go**. Its root advancement is granted automatically when you enter the world, and every other advancement hangs off it. An advancement only exists if the content it needs is turned on in the [config](getting-started/configuration.md).

| Advancement | Type | How to earn it |
|---|---|---|
| **Forged in Flames** | Goal | Obtain a full set of Kasai armour (helmet, chainmail, leggings and boots). |
| **Fire Up the Furnace** | Goal | Obtain a Kasai Ingot. |
| **Head in the Clouds** | Goal | Obtain a full set of Latharium armour (helmet, chestplate, leggings and boots). |
| **First Steps Underground** | Task | Obtain a Tamrelite Gem. |
| **Into the Ancient Depths** | Task | Obtain a Pendorite Gem. |
| **Sap to Syrup** | Task | Collect Maple Sap from a Maple Tap using a glass bottle. |
| **A Token of Love** | Task | Feed a Golden Beetroot to a tamed animal to grant it passive healing. |
| **Spore Wars** | Task | Kill a [Fungal Zombie](creatures/fungal-zombie.md). |
| **Sweet Tooth** | Goal | Obtain a Blueberry Pie, a Green Apple Pie, a Strawberry Pie and Maple Pancakes. |

:::note
Turning content off removes the advancements that need it.
:::
